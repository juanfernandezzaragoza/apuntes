El problema del _bootstrapping_ o problema del arranque es el problema de cómo dar el primer paso de un círculo virtuoso. Por ejemplo, un [[tejido de cooperación]] puede sostenerse a sí mismo, pero para eso tiene que existir. Antes de existir, necesita empezar a existir. El problema de cómo lograrlo es el problema del _bootstrapping_. 

Otro ejemplo está en los [[Tejidos y fundamentos/efectos de red|efectos de red]]. Una vez que un sistema alcanza una masa crítica, podría crecer y [[desplazamiento|desplazar]] a otros sistemas, pero hay un problema de cómo llegar a la masa crítica antes de que los efectos de red favorezcan participar del nuevo sistema.

Por el problema del arranque, no basta contar con el diseño de un sistema alternativo, sino que también hace falta contar con una estrategia para alcanzar la masa crítica y para incentivar participar del sistema antes de que el sistema pueda recompensar la participación por sí mismo.
