Un sistema de validación de acciones es un sistema que permite que un grupo llegue a consensos respecto de cuándo sucede una acción. Encontrar un consenso respecto de cuándo sucede una acción es importante para [[escalar el reconocimiento]], dado que para que el grupo pueda recompensar o penalizar acciones específicas, debe poder validar cuándo suceden.
